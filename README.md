## 🔨 Now building

- **🌐 debrief-site** — public landing page for Debrief
  Hand-built static HTML for [debrief.run](https://debrief.run), deployed via GitHub Actions to Cloudflare Pages. No framework, no build step. `active`

- **🏃 Debrief** — training-reflection app for distance runners
  Syncs from a Suunto watch into a local SQLite pipeline and renders a static, chart-forward dashboard — VDOT paces, 80/20 intensity checks, effort-colored trend bars, and weekly training-log entries. Zero infrastructure by design: no server, no accounts. `active`

- **🗄️ theDBSample** — collegiate running results research database
  CLI-driven TypeScript crawler and normalizer that builds a local SQLite database of college track and cross-country performances. Provenance-tracked, conference-level batch ingestion, resumable wave processing. `active`

- **🎯 Seedmark** — recruiting benchmark tool for high-school runners
  Pin target college programs, overlay division and conference recruiting standards, and see where a projected time would land on a real roster. Next.js 16, React 19, TypeScript, Tailwind v4, vitest. `active`

- **📦 RunDB** — clean-source data engine behind Seedmark
  Legally sourced college performance facts with per-record provenance, served through a versioned data contract. Every fetch passes a policy firewall; ships code, never data. TypeScript, SQLite. `active`

- **🤖 ai-portfolio-dm** — AI-powered portfolio with honest fit assessment
  Recruiters chat with an LLM grounded in real work history; paste a job description and get a genuine fit verdict, not a sales pitch. Admin panel for managing all content. Next.js 16, React 19, Supabase, Drizzle ORM, Claude API. `shipped`

- **⏱️ ChiroTracker** — QR badge time clock for a small practice
  Employees scan a badge on a tablet kiosk to clock in and out; the owner gets a reporting dashboard with time-entry editing, late-arrival flags, and CSV export. PWA with offline support, TypeScript, SQLite, Fly.io. `shipped`

- **🧠 Memex** — LLM-maintained personal knowledge base
  Obsidian vault where Claude compiles, cross-links, and audits notes on decisions, project context, and hard-won lessons. Three verbs: compile, query, audit. Markdown and git, no custom code. `active`
